Theme setup in Compose

Theme.ktMaterialExpressiveTheme with dynamic color
enum class ThemeSetting { System, Light, Dark }
 
@OptIn(ExperimentalMaterial3ExpressiveApi::class)
@Composable
fun SkimTheme(
    theme: ThemeSetting,         // Theme in 12
    incognito: Boolean = false,  // 09b, 09c
    content: @Composable () -> Unit,
) {
    val dark = incognito || when (theme) {
        ThemeSetting.System -> isSystemInDarkTheme()
        ThemeSetting.Light -> false
        ThemeSetting.Dark -> true
    }
    val ctx = LocalContext.current
    val dynamic = Build.VERSION.SDK_INT >= 31
    val colors = when {
        dynamic && dark -> dynamicDarkColorScheme(ctx)
        dynamic -> dynamicLightColorScheme(ctx)
        dark -> SkimDarkColors
        else -> SkimLightColors
    }
    MaterialExpressiveTheme(
        colorScheme = colors,
        motionScheme = MotionScheme.expressive(),
        typography = SkimTypography,
        content = content,
    )
}
 
// Shapes stay at the defaults.
// Motion in components:
// MaterialTheme.motionScheme.defaultSpatialSpec()

Setup and build rules

deployed_codeDependenciesmaterial3 1.5.0-beta01 and androidx.webkitfor incognito profiles. No material-icons.
text_fieldsFontBundle Google Sans Flex in res/font and listit in Open-source licenses (12).
interestsIconsMaterial Symbols Rounded as vector drawables,weight 400, grade 0, size 24. List on 17.
paletteFallback colorsBelow Android 12, use the schemes above;dynamic color everywhere else.
touch_appTouch targets48 or more, even where the visiblebutton is 40 or 32.
accessibility_newContent descriptionsEvery icon button has one; use thearia-label text from these boards.
text_snippetStringsEnglish copy as drawn, in strings.xml,with plurals for counts (1 tab, 7 tabs).
more_horizNo dot separatorsNever join pieces of text with a dot. Useseparate elements, a new line or a sentence.
scheduleDates and timesDevice locale. Lists group by Today,Yesterday, then Earlier this week.
publicFaviconsThe site icon when it has one, else itsfirst letter on a Cookie4Sided tile.
animationMotionMotionScheme.expressive() everywhere.Remove animations shows still frames.
fullscreenEdge to edgeThe top 24 on each board is the status bar.Use WindowInsets; pages run under the toolbar.
webWeb page colorsPages drawn in 05 to 05d and 06 to 06d aresample site content, not app tokens.
auto_awesomeSkim AI colorTertiary and the Sunny shape only for AI.Primary marks selection and main actions.
dark_modeDark themeIncognito always, and every screen whenTheme is Dark (12). Same roles, dark values.
tuneDynamic color tweakBoards preview four seeds in the tweak panel.The app reads the real scheme from the system.
