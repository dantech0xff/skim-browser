Write all plan prose (plan.md, phase files, coverage matrix) in Vietnamese with full diacritics. Keep code identifiers, file paths, library names, versions and UI copy strings in English.

**Why:** The user's orchestrated /ak:plan runs for skim-browser request this explicitly; research and scout reports in plans/reports/ are also Vietnamese.

**How to apply:** Any plan or report for this repo. English section headings matching the canonical phase template are fine (tool parsing); body text in Vietnamese. See [[reference-ak-plan-cli]].
